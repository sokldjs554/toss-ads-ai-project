## 재현

저장소 루트에서 개발 의존성과 Playwright Chromium을 설치한 Python으로 실행한다. `--out`에는 비어 있는 새 경로를 지정한다.

```bash
python scripts/verify_live_records.py \
  --run-id features-20261020-run3 \
  --out /tmp/preflight-live-records-new
```

`--run-id` 대신 `--report evals/reports/live_features/features-20261020-run3.json`도 지원한다. 해당 보고서가 현재 UI에서 가장 최신이어야 하며, 새 보고서가 추가되면 그 보고서를 지정해야 한다. 기대 수치는 실행 시 JSON에서 읽는다. 스크립트는 로컬 Streamlit을 `PREFLIGHT_FORCE_DEMO=1`로 시작하며 서버 환경의 API 키를 제외한다. 기록 화면만 열고 브라우저에서 외부 모델 API 요청이 발생하면 차단하여 실패 근거에 남긴다.

이번 환경에서는 한글 폰트가 있는 별도 Fontconfig 설정과 설치된 브라우저 경로를 사용했다. 필요하면 `FONTCONFIG_FILE`, `PLAYWRIGHT_BROWSERS_PATH` 또는 `PREFLIGHT_CHROMIUM`을 지정할 수 있다. 실행 스크립트·UI 파일·각 저장 보고서의 SHA-256은 결과 JSON에 있다. 실패나 부분 실행도 결과와 가능한 실패 화면을 남기며, 기존 출력 폴더를 덮어쓰지 않는다.
