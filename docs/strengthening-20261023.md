기준 main/Pages/Render는 `d48405926713eada260eb81049d1cc4ba2f65f68`. 시작 시 로컬 미커밋 변경 없음. 과거 CI 4,441, 공개 브라우저 32는 그 기준의 기록이며 이번 검증 수가 아니다. 작업 브랜치는 `fix/preflight-evidence-20261023`이다. 원격 main과 Render live 배포를 연결 도구로 확인했다. 최종 배포/브라우저 증거는 이 문서에 연결되는 실행 기록에서 확인한다.

원인 분석: 기존 탐지기는 요일·추세·변동성과 최소 표본을 반영한다. 짧은 과거 기준에서 최근 기간을 외삽하면 가능한 기울기의 오차가 커지고, 한 광고세트의 변화가 기준 기간에 섞이면 추세·잡음으로 흡수될 수 있다. 이 때문에 단순 변화율만으로는 알림이 나지 않는다. 반대로 계속되던 추세를 새 사건으로 알리거나 회복한 사건을 최근 사건으로 알리는 것도 오류다. 따라서 임계값이나 7개 ID 예외로 해결하지 않았다.

후보 [a545f60](https://github.com/sokldjs554/toss-ads-ai-project/commit/a545f60)은 요일 고정효과·공통 선형 추세·수준 변화 계수를 이전과 이후 관측으로 함께 적합했다. 기울기를 제거한 것이 아니라 설계행렬의 공선성으로 인한 수준 변화의 불확실성을 유지했다. 기준 잡음/표본 하한과 양의 잔차 자기상관 보정, 최근 지지 조건을 두었고 두 모델을 검사하므로 비교 보정도 강화했다. 전환율 하락과 역지표 CPA 상승의 해석을 별도 검사했다. 분석용 회귀는 먼저 2실패/7통과, 관련 66개는 통과했다.

같은 24개에 제공자 없음 상태를 주입한 결과: 보류 19/24, 기존 확정 block 유지 5/24, 통과 0/24, 성공한 모델 호출 0회. 평가 입력에 AI가 미리 작성한 중립 수정문으로 재검사한 결과 잔여 위반 0/24다. **실행 중 모델이 생성한 수정안의 성공률이 아니다.** [원본 결과](../evals/reports/strengthening-20261023/policy-final.json).

이미 있는 [동일 입력 실제 모델 비교](../evals/reports/compare_live.json)는 2026-10-18 UTC 실행, GPT-4o, 프롬프트/정책 2026.10.4, 총 110개다. 이번 새 실험으로 계산하지 않는다. 기존 개발 98개에서 모델만의 정상 수정 요청 13/32, 결합 3/32이나 결합은 정상 5/32를 보류했다. 당시 holdout 12개에서 위험한 통과는 규칙 2/10, 모델 1/10, 결합 0/10이고 결합 보류 1/12다. 코드에 유리한 라벨, 비교 전용 프롬프트 차이, 수정안 검사 단계 차이, 소표본·단일 실행 한계가 있다. 따라서 결합이 모든 환경에서 더 정확/저렴하다는 결론은 아니다.

사람 선호의 선택 일치 **21/28에는 공동 보류 1쌍 포함**. 56응답을 56독립 광고 정답으로 세지 않는다. 기존 모델 판단과 사후 대조한 자료도 새 독립 실험이 아니다.

| 공동 검수 | 기존 역할·배정·낙관적 revision·UUID 영수증·제한 DB API를 그대로 회귀 검사 | 운영 계정으로 로그인/저장/재접속/재배포 후 내용 대조는 이번 실행에서 하지 않음 |

기본 실제 제공자 외에 **명시적으로 주입한 제공자**는 기존 테스트/고정 평가의 자체 비용 장부를 따른다. 그 경로까지 새 런타임 예약기가 보호한다고 말하지 않는다. 가격표에 없는 모델·초과 크기·사용량 불명은 호출 전 또는 응답 후 보류하며 예약을 돌려주지 않는다. 제공자 공식 비용을 다시 확인하고 계정 차원의 하드 지출 제한을 설정한 뒤 실제 사용해야 한다. 이번 작업의 유료 API 호출은 0회다.

응답을 받았지만 모델/사용량이 확인되지 않은 경우에도 예약 유지와 함께 `cost_estimated`/실패 횟수를 남긴다. 요청 전 비용 차단은 실제 전송 실패로 세지 않는다. 비용 미확인 표시가 빠지던 실패를 별도 재현한 뒤 보완했다. 첫 공개 브라우저 실행은 42항목 통과/1실패였으며, 평가 제목이 렌더링된 직후 아직 표시되지 않은 다운로드 버튼을 조회했다. 검증기는 버튼 표시를 기다리고 실제 JSON을 내려받아 원문 필드가 없는지 확인하도록 바꿨다. 최초 실패는 [Actions 기록](https://github.com/sokldjs554/toss-ads-ai-project/actions/runs/39933548393)에 보존한다.

서버 접근키 설정만으로 전체 production 준비가 끝난 것이 아니다. 서버 비용으로 불특정 사용자를 받기 전에는 사용자별 인증·영속 누적 quota·속도 제한·배포 간 장부 보존이 필요하다. 지금은 운영자 동석의 제한된 합성 파일럿 절차만 준비됐다. 공동 검수의 인증은 모델 실행 권한과 별개다. 기존 운영 DB 계정·검수 자료는 변경하지 않았다.
