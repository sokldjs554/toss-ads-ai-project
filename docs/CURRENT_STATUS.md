## 수정한 문제와 남은 문제

- **정상 쿠폰 문구의 잘못된 반려:** 다른 단어 내부 조각이 정규화 중 연결되는 문제를 수정했다. 금지어 한 개 삭제는 사용자 요청에 따른 별도 정책 변경이다. [원인·회귀·남은 경계](normalization-boundaries-20261023.md).
- **실패 처리·저장:** 제공자·인용·응답 구조 실패는 보류하며 LIVE를 DEMO로 바꾸지 않는다. 호출 전 비용 예약, SDK 재시도 제한, 계정별 기록 접근을 적용했다. 오류 분류 필드가 저장을 막던 결함은 격리 실제 DB와 모의 SDK로 전후 확인했다. 새 실제 제공자 장애 실험은 아니다.
- **모델 수정 사유의 구체성:** [마지막 도구 사례](https://github.com/sokldjs554/toss-ads-ai-project/blob/c51d574eaf7a0fc90c09f01ed8e996a57fce98a8/docs/operating-pilot-20261024/session-02-result.md)의 수정문에는 구매 조건이 있지만 모델은 조건 누락을 지적했다. 구체적으로 어떤 조건이 부족한지 확실하지 않다. 코드 검사 통과를 모델 의견의 정답으로 간주하지 않고 수정 필요로 저장했다. 이 품질 문제는 미해결이다.
- **조건 확인 범위:** 코드가 값·뜻을 대조하는 것은 자동결제·심사 조건·최소 금액·기간·1인 횟수·제외의 여섯 종류다. 신규 고객 한정·첫 달만 등은 코드가 확인하지 못하며 모델·사람에게 의존한다. [구현과 상세 경계](../guardrails/grounding.py).
- **정책 평가:** 새 합성 평가의 위험 사례 16건 중 위반을 놓친 승인 4건이 남았다. 규칙·DEMO와 AI 초안 정답 기준이며 독립 사람 검수 전이다. 최신 LIVE 정확도로 해석하지 않는다.
- **성과 인사이트:** 지속 하락을 놓친 사례가 개발 7/12, 새 자료 13/24다. 개선 후보는 새 자료에서 나빠져 철회했다. [평가 원본·철회 이유](strengthening-20261023.md).
- **사람 선호:** 28쌍×2명=56응답, 선택 일치 21/28에는 공동 보류 1쌍이 포함된다. 정책 정확도나 새 독립 성능 실험이 아니다.
- 상용 고객·장기 운영·업무 시간 절감·독립 정책 정답은 아직 입증하지 못했다.

## 경쟁 서비스 관찰

[Ahrefs 관찰 원본과 검수표](https://github.com/sokldjs554/toss-ads-ai-project/blob/f55418d5f1d2a615a402458dc4bd4cf02f8e2df7/docs/competitor-comparison-20261024/RESULT.md): 본인 직접 생성 3회, 중복을 제외한 15문구. 가격 사례 10문구 모두 29,000원을 포함했다. 제공하지 않은 구체 주장은 AI 분석상 3문구에서 관찰했다. 독립 오류율이나 동일 조건 Preflight LIVE 우열 비교가 아니다.

## 저장 공간과 기여의 구분

LIVE 파일럿 저장과 일반 공동 검수 공간은 별도다. 일반 공동 검수의 [2026-10-22 설치·권한 증거](evidence/team-review-neon-20261022/README.md)는 설치 완료를 입증하지만 그것만으로 공개 앱 저장·재접속까지 입증하지는 않는다. LIVE의 6건을 공동 검수 시험으로 합산하지 않는다.

본인은 범위·우선순위 결정, 결과 검수, 사람 선호 응답 수집, LIVE 입력·판단 저장·재접속, 경쟁 서비스 실행을 맡았다. AI 도구는 설계 후보·코드·테스트·배포·자료 분석·문서 작성을 지원했다. 커밋 작성자 이름만으로 본인 직접 구현을 주장하지 않는다.

## 과거 기록 읽는 법

날짜가 있는 평가·실패 로그는 당시 조건을 보존한다. 최초 2건 사용, 이전 배포 SHA, 이전 CI 수는 해당 시점의 기록이며 최신 합계는 이 문서가 기준이다. 원자료·정답·모델 결과를 현재 수치에 맞춰 고치지 않았다.
