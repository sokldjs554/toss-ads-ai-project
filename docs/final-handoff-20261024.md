## 본인 LIVE 사용·비용

최종 읽기 전용 서버 조회: **본인1명, 요청6건, 사람 감사6건(승인3·수정 필요3)**. 요청 수는 사용자 수·독립 과제 수가 아니다. 모델 `gpt-4o-mini-2024-07-18`, 프롬프트 `live-rag-tools-4`, 정책 `2026.10.7`.

본인 계정 실제 API는 **10회 성공·실패0**, 입력30,688·출력1,428토큰, 기록 단가 기준 **추정$0.005459**다. 이 수치는 본인 계정6요청만의 합계이며 전체 프로젝트 청구액이 아니다. 과거 자동 진단의 실패2회 비용 미확인은 그대로 남는다. 전체 파일럿은19요청·37서버시도, 예약$1.52로 현재 한도 소진이다. 예약액은 실제 청구액과 다르며 기존 기록 조회·다운로드는 새 호출이 아니다.

사용일 확인은 본인 답변으로 완료했다: **10월22·23·24일 실제 모델 LIVE 검토 사용(본인 확인)**. 현재 보유 서버 로그6건의 한국시간 날짜는24일이다. 세 날짜의 본인 확인과24일의 서버 로그를 서로 다른 근거 범위로 표시한다. 24일 RAG 사용 보고13:28–13:35, 도구 사용 보고14:00–14:24 및 재접속 보존 확인을 받았다. 이 구간은 사용자의 보고이며 자동 계측한 능동 검수 시간이나 절감 시간은 아니다.

최신 도구 요청 `2c194714-6a3c-4912-a485-e434e08b4044`는 입력 일치·실제 수정1회·도구 재검사 APPROVE를 확인했고, 마지막 모델 의견은 REVISE여서 본인이 edit로 저장했다. **실행·검토·저장·재접속 검증은 완료**다. 수정문에 조건이 있는데 모델이 누락을 지적한 의미 판단 과탐 의심은 별도의 모델 품질 한계이며 해결됐다고 쓰지 않는다.

## 경쟁 서비스 결과

Ahrefs 무료 광고 생성기에서 P23-05·09·17을 각각1회 실행했다는 본인 확인과 파일3개를 확보했다. 누적 내보내기 A / B+A / C+B+A에서 중복을 제외하면 **3생성·15문구**다.

- 가격 사례2개의10문구 모두29,000원 포함;37,000원0개.
- 15문구 중3개에서 제공 사실에 없는 구체 주장(특별 할인·품질 보장·한정 수량)을 관찰했다. AI 내용 분석이며 독립 사람 정답 오답률이 아니다.
- 다른11개는 주관적·불특정 주장 검수 대상으로 분류했고1개에서는 AI가 문제를 지적하지 않았다. 나머지12개를 자동 통과로 간주하지 않는다.
- Google Ads 자체·Adobe 실제 실행은 하지 않았다. 같은 입력의 새로운 Preflight LIVE 비교도 수행하지 않아 정확도 우열을 결론 내리지 않는다. 기존 Preflight 규칙/DEMO 참조와 실제 Ahrefs 생성 결과를 구분했다.

원본 업로드는 비공개 보존, 공개 자료는 해시·짧은 근거·검수 요약이다. 모델 ID·토큰·비용·지연·화면 캡처는 Ahrefs 내보내기에 없으므로 추정하지 않는다. 환경 네트워크 설정이 화면과 다르게 적용되는 문제는 사용자 브라우저 실행으로 작업을 이어간 것이며 환경 자체가 수정됐다는 뜻은 아니다.
