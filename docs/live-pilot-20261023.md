# 배포 LIVE 파일럿 설계·실행 장부

기준: `7767dcbe288fd9ceaf6b9fdc021f7ac4450ad388`. 사용자 요구·유료 API 승인은 2026-10-23 대화에 있다. 구현 선택과 실행은 AI 지원 작업이며 사용자 직접 코딩으로 주장하지 않는다.

## 구현 선택

- 기존 Python/Streamlit, 정책 카탈로그, 결정론 검사, PostgreSQL을 재사용한다. 별도 프로젝트·벡터 서비스·외부 에이전트 플랫폼은 만들지 않는다.
- RAG: 업종 필터 후 한글 문자 n-gram 기반 관련 정책·상품 사실 검색. 검색한 문서 ID/내용/해시를 고정하고 모델은 그 문서의 정확한 인용을 반환한다. ID·인용·광고 구절을 코드로 검증한다. 인용 존재는 의미적 함의나 정책 정답의 증명이 아니다.
- 도구 워크플로: Chat Completions의 실제 function tool calls를 사용한다. 모델이 `check_policy`에 수정 문구를 전달하면 기존 결정론 검사가 실행된다. 결과를 tool 메시지로 돌려주며 최대 두 수정안만 허용한다. 마지막에는 RAG 의미 검토 후 사람 검토로 넘긴다. 도구 코드 통과만으로 의미 검사를 통과했다고 표시하지 않는다.
- 전체 정책을 프롬프트에 넣는 기존 경로는 유지하되 RAG라고 재명명하지 않는다. 기존 코드 주도 재검사는 실제 도구 호출과 구분한다.
- 별도 `preflight_live_pilot` 스키마의 제한 파일럿: 인증된 본인 요청만 조회·검토. 전역/계정별 영속 비용 예약과 요청 ID 중복 방지. 기존 `preflight_team` 계정·자료는 읽거나 바꾸지 않는다.
- 실패 시 보류, DEMO 대체 없음. 운영 요약은 원문을 제외하고, 인증된 작업 기록에만 합성 입력·근거·검토 결과를 저장한다. 사람 검토 기록의 자동 브라우저 계정은 사람 참여로 집계하지 않는다.

## 사전 고정 실험

`evals/datasets/live_pilot_20261023.json`의 합성 4개 입력을 실행 전에 커밋한다. AI 초안 기대값이며 독립 사람 정답이 아니다. 실제 LLM 결과를 보고 입력·기대값을 바꾸지 않는다. 이 작은 실행은 연결·도구·인용 검증이며 일반 정책 정확도 실험이 아니다.

모델: `gpt-4o-mini-2024-07-18`. 가격 계산: 입력 $0.15 / 출력 $0.60 per 1M tokens (저장소 가격표, 청구 확정액 아님). 최대 출력 1,200 tokens. 요청 직전 전체 직렬화 메시지·도구 크기 상한과 예약액을 검사한다. SDK 재시도 0, 호출 timeout 30초. 요청당 최대 4회·수정안 최대 2개. 전역 예약 한도 $1, 사용자 한도 $0.50. 실패/사용량 미확인은 예약 환급 없음. 최초 4개 요청의 실제 예상 비용은 $0.10 미만이며 예약 상한은 요청당 $0.08, 총 $0.32다. 재접속·재배포 확인은 기존 요청을 조회하여 추가 모델 호출 없이 수행한다.

## 보존할 기존 한계

실제 호출 전 직접 수정·재검사 확인용 입력을 `live_pilot_manual_20261023.json`에 별도 고정했다. 첫 정상 RAG 기록에서 제목만 ‘가을 쿠폰 이용 안내’로 바꾸고 RAG로 재검사한다. 기존 네 입력·기대값은 유지한다. 추가 요청 예약 $0.08을 포함한 최초 실행 예약은 최대 $0.40이며 전체 누적 $1 상한은 그대로다.

지속 하락 개발 7/12 미탐·새 자료 13/24 미탐은 미해결. 후보는 악화되어 철회. 새 정책 위험한 통과 4/16은 사람 검수 전 AI 초안 기준. 사람 응답 56개=28쌍×2명, 일치 21/28에 공동 보류 1쌍 포함, AI 정확도 아님. 삭제한 금지어를 복구하지 않는다.

## 실행 상태

구현·배포 준비 단계. 새 실제 호출·공개 브라우저·사람 사용 결과는 아직 없다. 이전 4,453 테스트·47 브라우저 항목은 이 변경의 검증 결과로 재사용하지 않는다.

## 사용자 절차와 범위

서버의 `LIVE 검토` 화면에서 파일럿 접근키로 로그인한다. 네 가지 합성 예시 중 하나를 불러와 RAG 또는 도구 호출 경로를 실행한다. 검색한 근거·인용·코드 검사·모델 의견·수정 이력을 확인하고 검토 사유와 승인/반려/수정 필요를 저장한다. 직접 수정하면 이전 요청 ID와 연결된 새 요청으로 재검사한다. 승인되지 않은 광고를 게시하는 기능은 없다. 현재 화면의 직접 입력은 커머스 업종 합성 파일럿에 한정된다.

같은 계정·같은 입력은 재접속·배포 버전이 달라도 기존 기록을 반환한다. 조회는 새 API 호출이 아니다. 의도적으로 수정·재검사하려면 저장된 기록의 ‘직접 수정하고 재검사’를 사용한다. 이 경우 부모 요청을 포함한 별도 입력 해시가 생성되며 누적 한도는 유지된다. 요청 도중 서버가 재시작되면 결과 미확인으로 남기며 자동 재전송하지 않는다.

사람 파일럿 계정은 `person_unverified`, 자동 브라우저 계정은 `automation`으로 구분한다. 계정 발급·저장 기록만으로 실제 참여자 존재나 신원을 확인했다고 주장하지 않는다. 사용자에게 발급한 접근키는 저장소 밖의 비공개 인계 파일로만 전달한다. 사람이 두 경로를 수행한 날짜·작업 ID·문제와 대응을 별도 확인하기 전에는 사람 사용 0명/0건으로 남긴다.

## 검토 중 발견한 문제와 선택

모순 응답(APPROVE와 위반 finding 동시 반환)을 별도 실패 테스트로 재현한 뒤 보류하도록 했다. 인용의 위치·설명도 화면에 표시한다. 세션 내 요청 ID만으로는 재접속 중복 과금을 막지 못해 DB의 입력 해시 중복 검사와 전역 예약 잠금을 함께 사용한다. 직접 수정 시 고지 누락과 잘못된 입력의 선예약 문제도 보완했다.

새 DB API 생성 역할에 광범위 권한이 기본 부여되고 기존 관리 역할의 권한 축소 요청이 거부되어, 앱은 SQL로 만든 `preflight_live_app` 제한 역할을 사용한다. `preflight_live_pilot`만 접근하며 기존 공동 검수 테이블 읽기/수정과 시험 계정 수정 권한이 없음을 확인했다. 미사용 API 생성 역할은 사용자 승인 후 삭제했다. 제한 DB 접속정보의 Render 전송은 자동 승인 검토가 명시적 동의 부족으로 한 번 거부했고, 사용자 별도 승인 후 기존 환경변수를 보존하는 병합 방식으로 등록했다. 기존 공동 검수 자료 변경은 없다.

로컬 전체 첫 실행: **4,408 통과 / 1 실패 / 55 skip / 11 error** (489.82초). 실패는 기존 다섯 화면 기대값으로 새 LIVE 화면을 누락한 테스트이고 수정 후 해당 테스트는 통과했다. 오류는 Chromium 미설치·소켓 권한 제한이며, skip에는 격리 PostgreSQL 부재가 포함된다. 최종 전체 수치는 필요한 환경을 갖춘 CI의 새 결과로 기록한다.

## 아직 입증하지 않은 것

- 한글 bigram 검색의 독립 검색 recall, 의미적 인용 함의, 일반 광고 정책 정확도.
- 제공자 최종 청구액·계정 전체 과금 상한. 여기의 수치는 고정 모델 단가에 따른 이 경로의 보수적 예약/토큰 비용이다.
- 실사용자 운영 기간, 상용 고객, 팀 협업 효과, 사람의 검수 시간 절감.
- SSO/MFA, 계정 신원 인증, 불특정 다수 공개 유료 서비스 운영.

사용자는 목표·우선순위·비용 승인·Render 키 등록을 수행했다. 코드·테스트·자동 실행·문서 초안은 AI가 지원했다. 이번 구현을 지원자가 직접 작성한 코드라고 단정하지 않는다.
