# 배포 LIVE 파일럿 설계·실행 장부

기준: `7767dcbe288fd9ceaf6b9fdc021f7ac4450ad388`. 사용자 요구·유료 API 승인은 2026-10-23 대화에 있다. 구현 선택과 실행은 AI 지원 작업이며 사용자 직접 코딩으로 주장하지 않는다.

## 구현 선택

- 기존 Python/Streamlit, 정책 카탈로그, 결정론 검사, PostgreSQL을 재사용한다. 별도 프로젝트·벡터 서비스·외부 에이전트 플랫폼은 만들지 않는다.
- RAG: 업종 필터 후 한글 문자 n-gram 기반 관련 정책·상품 사실 검색. 검색한 문서 ID/내용/해시를 고정하고 모델은 그 문서의 정확한 인용을 반환한다. ID·인용·광고 구절을 코드로 검증한다. 인용 존재는 의미적 함의나 정책 정답의 증명이 아니다.
- 도구 워크플로: Chat Completions의 실제 function tool calls를 사용한다. 모델이 `check_policy`에 수정 문구를 전달하면 기존 결정론 검사가 실행된다. 결과를 tool 메시지로 돌려주며 최대 두 수정안만 허용한다. 마지막에는 RAG 의미 검토 후 사람 검토로 넘긴다. 도구 코드 통과만으로 의미 검사를 통과했다고 표시하지 않는다.
- 전체 정책을 프롬프트에 넣는 기존 경로는 유지하되 RAG라고 재명명하지 않는다. 기존 코드 주도 재검사는 실제 도구 호출과 구분한다.
- 별도 `preflight_live_pilot` 스키마의 제한 파일럿: 인증된 본인 요청만 조회·검토. 전역/계정별 영속 비용 예약과 요청 ID 중복 방지. 기존 `preflight_team` 계정·자료는 읽거나 바꾸지 않는다.
- 실패 시 보류, DEMO 대체 없음. 운영 요약은 원문을 제외하고, 인증된 작업 기록에만 합성 입력·근거·검토 결과를 저장한다. 사람 검토 기록의 자동 브라우저 계정은 사람 참여로 집계하지 않는다.

## 사전 고정 실험

`evals/datasets/live_pilot_20261023.json`의 합성 4개 입력을 실행 전에 커밋한다. AI 초안 기대값이며 독립 사람 정답이 아니다. 실제 LLM 결과를 보고 입력·기대값을 바꾸지 않는다. 이 작은 실행은 연결·도구·인용 검증이며 일반 정책 정확도 실험이 아니다.

모델: `gpt-4o-mini-2024-07-18`. 가격 계산: 입력 $0.15 / 출력 $0.60 per 1M tokens (저장소 가격표, 청구 확정액 아님). 최대 출력 1,200 tokens. 요청 직전 전체 직렬화 메시지·도구 크기 상한과 예약액을 검사한다. SDK 재시도 0, 호출 timeout 30초. 요청당 최대 4회·수정안 최대 2개. 전역 예약 한도 $1, 사용자 한도 $0.50. 실패/사용량 미확인은 예약 환급 없음. 최초 4개 요청의 실제 예상 비용은 $0.10 미만이며 예약 상한은 요청당 $0.08, 총 $0.32다. 재접속·재배포 확인은 기존 요청을 조회하여 추가 모델 호출 없이 수행한다.

## 보존할 기존 한계

지속 하락 개발 7/12 미탐·새 자료 13/24 미탐은 미해결. 후보는 악화되어 철회. 새 정책 위험한 통과 4/16은 사람 검수 전 AI 초안 기준. 사람 응답 56개=28쌍×2명, 일치 21/28에 공동 보류 1쌍 포함, AI 정확도 아님. 삭제한 금지어를 복구하지 않는다.

## 실행 상태

설계·입력 고정 단계. 새 실제 호출·배포·브라우저·사람 사용 결과는 아직 없다. 이전 4,453 테스트·47 브라우저 항목은 이 변경의 검증 결과로 재사용하지 않는다.
