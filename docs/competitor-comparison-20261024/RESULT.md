# Ahrefs 실제 생성 결과: 가격 보존과 추가 주장 구분

**Ahrefs 무료 Google Ads Copy Generator의 사용자 실행3회·고유 광고 문구15개를 분석했다.** 고정한 P23-05 → P23-09 → P23-17 순서로 입력을 그대로 넣고 각1회 생성했다는 사용자 확인을 받았다. 실제 제품은 Ahrefs이며 Google Ads 자체의 대화형 생성 기능을 실행한 것이 아니다.

가격 사실이 있는 두 사례의10개 문구는 모두29,000원을 포함했고37,000원은 남기지 않았다. 그러나 제공된 사실에 없는 할인·품질 보장·수량 제한이 각각1개 문구에서 추가됐다. 숫자 보존과 근거 없는 주장 추가를 별도로 기록한다. 전체 정확도나 서비스 우열을 계산하지 않는다.

## 원자료와 중복 제거

사용자가 제출한 파일3개는 누적 내보내기다. 첫 파일은 A, 둘째는 B+A, 셋째는 C+B+A를 포함한다. 따라서 파일 전체의30개 문구 출현을30회 생성으로 세지 않고, **3묶음×5개=고유15개**로 계산했다. A/B/C는 각각 P23-05/09/17로 연결하며 그 연결과 입력 동일성의 근거는 사용자 확인이다. 내보내기에는 요청 입력 자체가 없다.

- 모든 파일 헤더는 Korean·Formal이다. 화면 캡처나 모델 버전·요청ID·서버 토큰·호출 수·지연·청구 내역은 포함하지 않는다.
- UI 생성 동작3회와 내부 모델 API 호출 수를 구분한다. 후자는 알 수 없다. 파일명의 시각은 내보내기 이름이며 생성 지연이나 사람 작업시간으로 사용하지 않는다.
- 원본3파일은 비공개 보존했다. 공개 자료에는 SHA-256·파일 크기·묶음 순서와 짧은 근거 구절만 기록했다. [원자료 식별·요약](ahrefs-user-run-summary.json), [15개 문구별 검수표](variant-review.csv).
- [실행 전 입력](inputs.json)·[기존 채점 기준](rubric.json)의 해시는 [고정 기록](manifest.json)과 동일하다. 이 manifest의 실행0건은 준비 당시 상태로 보존하며 최신 상태는 본 결과를 따른다.

## 사례별 관측

| 사례·제공 사실 | 가격·원문 관측 | 제공 근거에 없는 구체적 주장 |
|---|---|---|
| P23-05: 초안37,000원, 사실29,000원 | 생성5/5개에29,000원,37,000원0/5 | 2번 문구의 “특별 할인”: 할인 행사·기준 가격이 제공되지 않음 |
| P23-09: “업계 최저”, 사실 없음 | “업계 최저” 원문은0/5개. 4번에 “최상의 상품”이라는 다른 최상급 표현 | 1번의 “품질 보장”: 보장 근거가 제공되지 않음 |
| P23-17: 정상 초안·사실 모두29,000원 | 생성5/5개에29,000원 유지 | 3번의 “한정 수량”: 수량 제한이 제공되지 않음 |

표의3개는 각기 다른 문구로, 전체15개 중3개에 해당한다. 이는 **AI 분석자가 확인한 추가 주장 사례3/15**이며, 독립 사람 정답으로 확정한 오답률20%가 아니다. 나머지12개를 모두 통과로 간주하지 않는다.

“품질 좋은”, “믿을 수 있는”, “프리미엄”, “최고의 선택”, “특별한 혜택” 같은 주관적·불특정 주장도11/15개에 있어 별도 사람 해석 대상으로 표시했다. 이11개와 위3개, AI가 문제를 지적하지 않은1개(P23-09의5번)는 검수표에서 상호 배타적으로 분류했다. 문제를 지적하지 않은1개 역시 실제 광고 승인이나 법적 적합성의 보증이 아니다. 이 하위 분류는 출력 설명을 위한 사후 코딩이며 실행 전 독립 성능 지표로 정해 둔 새 평가척도가 아니다.

## Preflight와의 비교 범위

| 구분 | Ahrefs 이번 자료 | Preflight 확보 자료 |
|---|---|---|
| 같은3개 원래 사례 | 실제 사용자 생성3회, 결과15개 | 과거 규칙/DEMO: P23-05 REVISE, P23-09 REVISE, P23-17 APPROVE |
| 수행 과업 | 기존 초안·상품 사실을 받아 새 문구 생성 | 원래 광고를 검사하고 판정하는 규칙/DEMO 경로 |
| 실제 모델 비교 | 모델 ID·토큰·비용 미공개 | 같은3개 입력의 신규 LIVE 실행은0건 |
| 워크플로 근거 | 제출된 텍스트 출력만 확인 | 별도 실제 LIVE 과제에서 수정·도구 재검사·사람 판단·저장·재접속 확인 |

Preflight의 과거3행은 [참조 자료](preflight-historical-reference.json)이며 이번 Ahrefs 모델과 동조건으로 새 실행한 결과가 아니다. 다른 입력의 Preflight LIVE 성공을 같은3사례의 성공으로 대체하지 않는다. 기존 LIVE에서 코드 검사를 통과한 수정문을 마지막 모델이 조건 누락으로 지적한 사례도 유지한다. 이번 Ahrefs 관측으로 Preflight가 더 정확하거나 모든 추가 주장을 잡는다고 결론 내릴 수 없다. Ahrefs 생성 결과를 Preflight 코드로 재검사한 실험도 이번에는 수행하지 않았다.

관측에 맞는 설계 설명은 **“이 표본에서는 가격 수정·보존 후에도 새로운 주장이 추가돼, 생성과 별도로 상품 근거를 검토할 필요가 관찰됐다”**다. 브랜드·검토·재검사 워크플로의 시장 내 최초성이나 독점성을 주장하지 않는다. Adobe 공식 설명에는 유사한 검토·재검사 기능이 있으며, 이번에 Adobe나 Google Ads를 실제 실행하지 않았다.

## 완료 범위와 한계

완료: 무료 생성기1개에서 본인 조작3회, 한국어·Formal 결과 수집, 누적 중복 제거, 고정 입력 연결의 본인 확인,15개 전수 AI 분석, 원본 해시와 검수표 보존. 에이전트 환경의 네트워크 차단은 사용자 브라우저 실행으로 업무를 이어간 것이며, 환경 오류가 해결됐다는 뜻은 아니다.

남은 범위: 독립 사람 내용 검수, 동조건 Preflight LIVE 비교, Google Ads·Adobe 실제 실행, 반복 실행 변동성, 상용 효과·작업시간 비교. 세 사례는 기존 공개 AI 합성 개발 자료이고 같은 페이지에서 내보낸 기록이므로15개 독립 표본이나 서비스 전반의 성능으로 확대하지 않는다. 정확한 모델 버전·생성 파라미터·내부 API 횟수·공급자 비용도 알 수 없다.

| 쓸 수 있는 사실 | 정확한 수치·분모 | 검증 조건·근거 | 쓰면 안 되는 확대 해석 |
|---|---|---|---|
| 무료 광고 생성기 실제 출력과 Preflight 설계를 대조 | Ahrefs1개·사용자 생성3회·문구15개 | 고정 합성 입력, 사용자 실행 확인,3개 업로드의 해시 | 경쟁 서비스 전체 검증, 자동 브라우저가 직접 실행 |
| 가격 불일치 수정·정상 가격 보존 관측 | 가격 사례2개·문구10개 중10개29,000원 | 숫자 문자열 검사·사용자 입력 확인 | 전반 정확도100%, 모든 조건 보존 |

기여: 사용자가 Ahrefs에서3회 직접 실행하고 파일을 제출했으며 입력·순서를 확인했다. AI는 입력·출력 묶음 대조, 중복 제거, 숫자 집계, 내용 검토 초안과 기술 인계를 작성했다. 사용자 실행 확인을 독립 전문가 품질 평가로 바꾸어 표현하지 않는다. 이번 분석의 추가 유료 모델 호출·Preflight 한도 변경·배포 변경은0건이다.
