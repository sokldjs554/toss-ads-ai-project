# 사용자 브라우저로 실행할 경우: 고정 입력3개

현재 자동 실행 환경의 정책 반영 문제로 경쟁 모델 출력은0건이다. 아래는 사용자가 원할 경우 본인 브라우저로 실행할 수 있는 대체 절차이며, 실행 결과가 아니다. 원래 고정한 `generation_input`을 그대로 옮겼다.

1. [Ahrefs 무료 Google Ads 문구 생성기](https://ahrefs.com/writing-tools/google-ads-generator)를 연다. 가입·결제가 필요하면 실행을 멈추고 그 상태만 알려 준다.
2. 언어 선택에 한국어가 있으면 한국어, 어조는 기본 Formal을 유지한다. 한국어를 지원하지 않으면 번역하거나 영어로 대체하지 않고 그 상태를 알려 준다.
3. 아래 입력을 사례별로 한 번씩 사용한다. 이전 입력을 전부 지운 뒤 다음 입력을 넣는다. 생성 결과를 보고 입력을 바꾸거나 재생성하지 않는다.
4. 결과 전체(기본5개가 나오면5개 모두)를 사례 ID와 함께 복사하거나 화면으로 보존한다. 실패·보류도 그대로 남긴다. 공개 페이지에 보이는 모델명·시각·요금 표시가 있으면 함께 기록한다. 키·계정정보는 포함하지 않는다.
5. 세 결과를 이 대화에 전달한다. AI가 숫자·근거 없는 표현·정상 가격 유지 등을 고정 규약으로 분석한다. 이 실행은 사용자 조작으로 기록하고 자동 실행이나 사람 전문가 정답 검수로 집계하지 않는다.

Preflight 정책 판정과 광고 생성기의 출력을 같은 정확도로 비교하지 않는다. 새로운 Preflight LIVE 실행은 요청하지 않으며 예약 한도도 바꾸지 않는다. 두 서비스의 동조건 실제 모델 비교가 끝났다고 선언하지 않는다.
