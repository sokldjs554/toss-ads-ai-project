## 고정 사례와 실행 규약

[입력](inputs.json)과 [채점 규약](rubric.json)을 새 경쟁 모델 실행 전에 고정하고 [해시](manifest.json)를 기록했다. 사례는 기존 P23-05(판매가37000원/근거29000원), P23-09(근거 없는 업계 최저), P23-17(판매가29000원/일치 근거)이다. 기존 공개 AI 합성 자료이며 사람이 검수한 독립 정답이 아니다. 새 holdout 성능으로 표현하지 않는다.

- 원문·사실은 그대로 유지한다. 검토 기능에는 `review_input`, 생성 기능에는 `generation_input`을 사용한다. 두 과업의 점수를 합치지 않는다.
- 한국어와 공통 문맥을 전달할 수 없는 경우 비교 불가로 기록한다. 입력을 줄이거나 번역한 결과를 동일 조건으로 비교하지 않는다.
- 사례당 최초1회만 실행하고 모든 변형 결과를 보존한다. 유리한 출력 선택·재생성·정답 사후 수정은 하지 않는다.
- 서비스 자체의 판정이 없는 생성기에서 정책 판정 실패율을 만들지 않는다. 수정안의 숫자·사실 보존과 별도 사람 판정을 기록한다.
- 실제 출력·화면·표시 모델·시각·알려진 비용·실패를 기록한다. 비용 미공개는 unknown, 기능 미확인은 unverified, 접근 차단은 blocked다. 이를 성능0점으로 바꾸지 않는다.
- 결제·광고 게시·타인 계정 사용·외부 연락은 하지 않는다. 기존 허용된 계정이나 무료 공개 기능만 대상으로 한다.

기존 Preflight의 같은3사례 규칙/DEMO 결과는 [과거 참조](preflight-historical-reference.json)에 분리했다. 이는 새 LIVE 결과가 아니다. 현재 LIVE 예약 한도는 소진됐으며, 이번 조사에서 새 Preflight 모델 호출이나 한도 변경은 하지 않았다. 실제 동조건 LIVE 비교를 추가하려면 실행 예산을 별도로 정해야 한다.

## 실행을 막은 조건과 다음 단계

사용자는 사용 가능한 경쟁 서비스 계정이 없다고 답했다. 따라서 신규 가입·구매 없이 Ahrefs 무료 공개 생성기를 우선 실행 대상으로 정했다. Google Ads·GenStudio는 계정 미확보로 실제 실행 대상에서 보류한다. Ahrefs 역시 무료 표시만 확인했으며 실제 생성·한국어 지원·로그인 요구는 아직 관찰하지 못했다. 사용자가 환경 설정에서 `ahrefs.com`을 허용하도록 요청한 상태다.

현재 환경은 프록시가 정상 응답하지만 Google Ads·Adobe 목적지에 `CONNECT tunnel failed, response 403`을 반환했다. `curl` 종료코드는56이다. 이전의 프록시 연결 거부와 다른 오류다. [실제 명령·오류 로그](access-probe.json)를 보존했다. 환경 상태는 restricted/enforced이며 두 호스트와 Ahrefs가 허용 목록에 없다. 프록시·정책을 변경하거나 다른 실행 호스트로 우회하지 않았다.

연결 도구도 확인했다. 검색된 Ahrefs 플러그인은 SEO 분석, Adobe 플러그인은 Creative Cloud/Acrobat 중심으로 설명되며 이번 대상인 광고 문구 생성기·GenStudio 실행 기능이 확인되지 않았다. 도구를 설치하면 동일 기능을 실행할 수 있다고 가정하지 않는다.

실제 실행 재개에는 다음이 필요하다.

1. Google Ads 또는 GenStudio의 본인 사용 가능한 계정·제품 권한 확인. 비밀번호·키를 채팅이나 저장소로 받지 않는다.
2. 실행 환경 설정에서 선택한 서비스의 도메인을 허용하고, 로그인·정적 자원·생성 요청 도메인은 실제 필요가 확인된 것만 추가한다. 현재 확인한 시작 주소는 `ads.google.com`, `experience.adobe.com`, `ahrefs.com`이다. 허용된 대화형 브라우저 환경이 마련돼야 한다.
3. 계정이 없다면 Ahrefs 공개 생성기를 우선 접근 후보로 삼는다. 생성 비교는 가능 후보지만 정책 검토 비교 완료와는 다르다. 로그인·추가 비용·캡차가 나오면 해당 상태에서 멈춘다.

[관찰표](observations.csv)의9행은3서비스×3사례의 **미실행 자리표시자**이며 평가 응답이 아니다. 현 상태에서 모델 품질·우열·실사용 생산성에 대한 결론을 내리지 않는다.
