# 2026-10-20 작업 재개·검증 기록

## 범위

중단 지점 `d3ef1848f5e4df4f426f97f120bedfd9b96b9ae6`에서 이미지·소재 퀄리티·성과 리포트·운영·라벨링의 검토를 이어갔다. 이 커밋의 기존 CI와 Pages는 이미 성공한 상태였다. 첨부 화면에는 이전 검토의 작업명과 진행 상태가 있었지만 상세 결론은 없어서, 이번 체크아웃에서 직접 재현한 문제만 수정했다.

기능을 새로 확장하거나 실제 운영 효과를 측정한 작업은 아니다. 코드·문서의 불일치와 재현한 결함을 고치고, Python 3.11 전체 검사 및 실제 브라우저 흐름을 확인했다. 실제 AI 제공자와 유료 API는 호출하지 않았다.

## 과거 평가와 현재 검사를 구분하는 방법

`evals/reports/insights_controlled.json`과 `evals/datasets/perf_scenarios.jsonl`은 변경하지 않았다. 원래 엔진 지문 `fe53a3d060030913`도 그대로다. 보고 수치를 수정한 현재 엔진의 지문은 `83a47efd048e8ad3`다.

현재 결과는 별도 [insights_regression.json](../evals/reports/insights_regression.json)에 저장했다. `engine_changed_after_holdout: true`, `holdout_role: "regression"`으로 표시하며, 이미 본 53개 시나리오의 판정·집계가 이전 기록과 같은지 확인한다. 기존의 **이상이 없는 4개 중 2개에 잘못된 알림**도 그대로 남는다. 이 결과를 새 독립 평가나 실제 광고 데이터의 정확도로 소개하지 않는다.

`--regression`을 빼면 동결 이후 엔진 변경으로 기본 게이트가 실패한다. 해당 옵션을 사용해도 지문 누락·충돌이나 수치 기준 위반은 허용하지 않는다. 과거 보고서를 출력 경로로 지정하면 거부한다.

## 남겨 둔 한계

- 대화 해석의 알려진 6개 사례는 그대로다. 바꿔 쓴 한국어·영어 지시문, 이모지 문자, 등록되지 않은 업종, ‘40대 이상’, 여러 낱말의 말투 설명을 충분히 처리하지 못한다. `strict xfail`로 남겨 실제로 고쳐지면 예상 밖 통과가 드러나도록 했다.
- 새 기능의 실제 LLM·비전 모델 성능, 광고 성과와 품질 점수의 관계, 실제 광고주 사용 효과는 측정하지 않았다. 기존 실제 GPT-4o 기록은 이번 검사 결과와 섞지 않았다.
- 검수 대기열은 세션 단위 메모리 상태이며 실제 권한·알림·영구 저장 장치가 아니다. 독립 라벨러도 없다.
- GitHub Pages 실행판은 상품 주소의 직접 가져오기와 래스터 이미지 읽기를 지원하지 않는다. 예시 페이지·붙여 넣은 HTML·SVG로 확인한다.
- 기존에 기록된 브라우저 장시간 유휴 후 Pyodide 오류는 이번 수정으로 해결됐다고 주장하지 않는다.

```bash
export PREFLIGHT_FORCE_DEMO=1
unset OPENAI_API_KEY ANTHROPIC_API_KEY
python -m pytest -o addopts='' -q -ra
```
