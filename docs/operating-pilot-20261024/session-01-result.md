사용자는 **13:28–13:35, 재접속 후에도 보존**됐다고 응답했다. 이는7분의 사용자 보고 구간이며 능동 작업시간을 계측한 값이 아니다. 최초 실행13:17은 이 구간 밖이므로 처음 입력·진단을 포함한 전체 작업시간으로 사용하지 않는다. 수동 대조군이 없어 시간 절감 근거도 아니다. 재접속 보존은 사용자 확인, 승인 감사 존재는 서버 확인으로 구분한다. 원본 업로드 JSON은 변경하지 않고 비공개로 보존한다.
