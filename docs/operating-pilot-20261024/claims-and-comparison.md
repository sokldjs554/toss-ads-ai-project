채용 요건과 연결되는 근거는 관련 정책·상품 근거 검색 후 실제 모델의 인용 생성(RAG), 실제 모델의 check_policy 선택·수정·재검사·사람 전달(도구 호출 워크플로), 그리고 인증·영속 기록·비용·실패 처리다. 도구 경로의 마지막 RAG 재사용은 두 방식이 완전히 독립된 시스템이라는 뜻이 아니다. 전형적인 자율 에이전트 전체를 구현했다고 부르지 않는다. 채용팀이 제한적 개인 프로젝트 사용을 production 경험으로 인정하는지는 채용팀 판단이며 완료 처리하지 않는다.

## 경쟁 서비스는 전체가 아닌 관찰 가능한 표본

이번 우선순위는 반복 사용·효과 측정·실패 대응이다. 경쟁 서비스 내부 모델·프롬프트·검색·안전장치는 공개 화면만으로 추정하지 않는다. 예비 비교 후보는 Google Ads의 생성형 광고 작성 기능과 Adobe GenStudio for Performance Marketing이며, 이 이름은 **후보 지정**일 뿐 현재 이용 가능·동등 기능·실행 확인을 뜻하지 않는다. 이번에는 타인 계정 사용·광고 게시·유료 서비스 구매·신규 계정 가입을 하지 않았고 실제 비교 실행0건이다.

후속 비교가 가능할 때 기존 P23-05(숫자 불일치)·P23-09(최상급 표현)·P23-17(근거 있는 정상 문구)를 동일 입력으로 먼저 고정한다. 가능한 서비스에는 동일한 프로젝트 정책과 상품 사실을 함께 제공한다. 근거 문서 입력이나 정책 심사를 지원하지 않는 제품은 N/A와 기능 차이를 기록하고 동일 정책 정확도 순위를 만들지 않는다. 생성 품질과 검토 품질은 다른 과업이다. 서비스별 결과를 보고 사례·요구 출력을 바꾸지 않는다.

[관찰 양식](comparison-observations.csv)에 서비스·edition·표시 모델·날짜·동일 문맥 제공 여부·출력·인용 존재/의미 지원·조건 보존·실패·재시도·비용을 기록한다. 표시되지 않는 모델 버전은 미공개로 둔다. 직접 사용할 수 있는 승인된 계정이 확보될 때만 실행하고, 접근 불가를 성능 실패로 점수화하지 않는다. 단일 실행·표본3개·공개 개발 사례라는 한계를 함께 보고한다. 공식 기능 설명을 실제 모델 실행 결과로 대체하지 않는다.

지속 하락 미탐 개발7/12·새 자료13/24, AI 초안 정답 기준 정책 위험 통과4/16은 유지한다. 이 준비·저장 오류 수정은 해당 품질 한계를 개선한 실험이 아니다.
