- **연체이자율** — 기본 문장: “연체 시 약정 금리에 연체 가산 이자율이 적용됩니다.”

- **설명서·약관 확인 권유** — 기본 문장: “계약 체결 전 상품 설명서와 약관을 반드시 읽어 보시기 바랍니다.”
