✅ Preflight — 광고가 올라가기 전에 확인이 필요한 구절을 먼저 찾습니다

상품 정보로 광고안을 만들고, 확인이 필요한 구절을 이유와 함께 보여 주고, 수정 제안을 다시 검사하며, 판단이 어려우면 담당자 확인으로 넘깁니다. 개인 프로젝트이며 어느 회사의 실제 심사도 아닙니다.

2026-10-24 확인된 사용 범위
본인 1명 · LIVE 요청 6건 · 판단 저장 6건(승인 3·수정 필요 3). RAG와 실제 도구 호출 경로를 사용했습니다. 합성 광고의 단기 파일럿이며 정책 정확도와 상용 효과를 입증한 결과는 아닙니다. 현재 상태·근거·남은 한계
직접 써보기 · 브라우저에서 실행

광고 작업 (브라우저 실행판)

서버 없이 브라우저(WebAssembly) 안에서 전체 앱이 돕니다. 예시를 골라 광고안 생성 → 검사 결과 → 수정 제안 → 직접 고쳐서 다시 검사까지 해 보세요. 예시 실행이라 실제 AI 호출은 없습니다. 처음 로딩 20~60초.

열기 → 새 기능 · 실제 API 실행 기록

수정 전후의 실행 결과

캠페인 대화, 이미지 검사, 성과 보고서, 광고 문구 비교와 생성 흐름을 실제 모델로 실행한 기록입니다. 첫 실행의 실패와 수정 후 같은 입력의 결과, 호출 수와 비용을 함께 확인하세요. 기록을 보는 동안 새 비용은 발생하지 않습니다.

서버 LIVE 검토

검색 근거와 수정안을 읽고 판단·사유를 저장하는 경로입니다. 운영자가 발급한 앱 접근키로 접속합니다. 기존 기록 조회는 새 호출이나 비용을 만들지 않습니다. 새 실행에는 예약 한도 확인이 필요합니다.
