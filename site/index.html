✅ Preflight — 광고가 올라가기 전에 확인이 필요한 구절을 먼저 찾습니다

상품 정보로 광고안을 만들고, 확인이 필요한 구절을 이유와 함께 보여 주고, 수정 제안을 다시 검사하며, 판단이 어려우면 담당자 확인으로 넘깁니다. 개인 프로젝트이며 어느 회사의 실제 심사도 아닙니다.

직접 써보기 · 브라우저에서 실행

광고 작업 (브라우저 실행판)

서버 없이 브라우저(WebAssembly) 안에서 전체 앱이 돕니다. 예시를 골라 광고안 생성 → 검사 결과 → 수정 제안 → 직접 고쳐서 다시 검사까지 해 보세요. 예시 실행이라 실제 AI 호출은 없습니다. 처음 로딩 20~60초.

열기 → 실제 모델 결과 · GPT-4o 실행 기록 재생

실제 실행 기록

GitHub Actions 에서 실제 GPT-4o 로 돌린 5개 사례의 처리 기록(단계·비용·판정 근거)과 1차→5차 평가 결과(문제 있는 광고 통과 다섯 번 모두 0건, 문제없는 광고에 수정 요청 14건 중 5→1건(1~4차)과 5차 13건 중 0건(라벨 1건 수정으로 분모 변경), 확신 보정 오차 0.14→0.06, 처음 보는 holdout 12건 포함)를 그대로 보여 줍니다.
